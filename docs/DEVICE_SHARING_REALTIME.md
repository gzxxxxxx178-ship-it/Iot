# 设备共享实时推送

实时遥测沿用一次性票据鉴权的 WebSocket 连接，连接只保存已认证账号，不保存设备权限快照。JSON 和旧纯文本 MQTT 遥测持久化后，统一按设备 ID 查询当前接收名单。

- 当前所有者及该设备已授权的共享账号可以接收；其他设备的共享关系不会授予本设备推送权限。
- 设备不存在、所有者为空或空白、设备停用或归档时，不向任何账号分发，包括残留共享记录中的账号。
- 每条消息查询一次设备和一次共享名单，向该账号的所有已打开连接发送。名单去重，单个连接发送串行化；失败连接移出会话池，不影响其他连接。
- 新增或撤销授权提交后，已有连接的后续消息按新权限分发，无需重新登录或重连。已经发送或已经进入分发过程的消息不能撤回。
- 实时推送授权变化不清除客户端已接收的数据；REST 列表、历史和控制继续执行各自的设备权限检查。共享权限不扩展到账号私有的自动化规则与报警。

本轮用 H2 实际持久化和已连接会话替身验证授权变化、跨设备隔离、无主设备残留共享以及设备生命周期；未连接真实 Broker、浏览器或微信真机，未部署。
