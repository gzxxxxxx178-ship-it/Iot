- 数据大屏已接入实时统计、设备状态分布、WebSocket更新和最近24小时温湿度趋势；使用小程序可滚动布局。

- 仪表盘补齐在线设备温湿度均值、水位均值、最新信号、联动与发送次数，以及温湿度趋势和设备最新读数。
- 实时监控页加入同页设备选择与启动/停止快捷控制，继续使用设备在线/启用校验、操作确认、真实命令接口和命令回执。

- Web 与小程序自动化目标统一为当前账号本人拥有、未归档且已启用的设备；后端在保存/启用规则及下发硬件命令前再次校验归属和可控状态，避免任意设备ID产生无效规则或绕过停用限制。

小程序的「工作台」和「我的」是原生入口/账号配置页，不对应 Web 的独立业务路由。工作台入口会标出「已接入」「部分迁移」或「未迁移」，避免将占位页误认为已完成。当前不能据此认定 Web 功能已全部迁移：Google OAuth 回调尚未迁移；登录会话不会跨小程序冷启动恢复；数据大屏采用移动端滚动布局；设备档案与数据图表采用移动端交互/布局。支付模块目前是支付宝沙箱扫码，不是微信原生支付。共享设备自动化未开放，Web 与小程序均限制设备所有者规则。

新增报警、自动化、AI与看板页面均使用统一真实请求模块。历史数据筛选以本地时区日期时间提交，边界在分页期间保持冻结；水位始终展示为传感器 ADC 原始值。看板趋势从认证接口读取服务端最近20条数据，按时间排序后聚合为最多8个点；状态柱图表示设备数量，不代表传感器趋势。自动化启动/停止动作可能下发硬件命令，用户必须在小程序确认后才能保存启用规则。

## 启动本机后端

使用已有且被Git忽略的开发配置，不以测试Profile替代真实后端：

```bash
cd java
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

WebSocket 默认来源白名单同时允许 Web 本地页 `http://localhost:5173` 和微信小程序 `https://servicewechat.com`。生产环境需在 `WEBSOCKET_ALLOWED_ORIGINS` 与 `CORS_ALLOWED_ORIGINS` 中都保留 Web 站点来源并加入 `https://servicewechat.com`；不要使用通配符。小程序连接使用短期票据认证，来源白名单不能替代票据校验。

默认Profile未携带本机数据库密码，直接启动会认证失败。现有dev配置已启动成功，地址为 `http://localhost:8080`。数据库、Redis和MQTT由后端配置负责，小程序不保存这些凭据。`GET /actuator/health`返回UP不能证明MQTT已连接或设备已上报；设备接口未认证返回HTTP401。

## 编译与登录

1. 首次导入前在 `miniapp/` 安装 npm 依赖（`npm install`），其中二维码编码库用于支付宝沙箱扫码；然后用 HBuilderX（`/Volumes/out/Applications/HBuilderX.app`）导入 `miniapp/`，运行到微信开发者工具（`/Volumes/out/Applications/wechatwebdevtools.app`）。
2. 微信工具打开 **`miniapp/unpackage/dist/dev/mp-weixin/`** 编译目录，不是源码目录。微信测试AppID为 `wx072082beff11b3e7`，位于manifest的mp-weixin字段，与根级DCloud AppID不同。
3. 「我的」默认后端为 `http://localhost:8080`。如需更换，仅填写根地址，不含 `/api`、查询参数或账号密码。旧版演示配置自动迁移为真实模式。
4. 「账号登录」使用现有系统账号。密码提交后输入框清空，令牌仅内存保存，重启后重新登录；本地仅保存后端地址。
5. 概览和设备页进入时刷新，也可手动刷新。历史查询冻结一次分页的截止时间，筛选变化后重置。
6. 如开发工具拦截本机HTTP，由开发者在该项目「详情→本地设置」启用本地调试选项「不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书」。仓库未关闭manifest域名校验，此选项不适用于发布。

模拟器可访问电脑localhost；真机的localhost指手机自身，需改电脑局域网地址。浏览器预览还受后端CORS限制。正式发布需单独完成合法HTTPS域名配置。

## 数据与控制语义

- 未登录、缺测或接口失败时不补入演示数据。切换地址、退出或认证失效清空真实数据，迟到响应不能恢复旧账号状态。
- 实时监控使用认证 REST 接口领取一次性短期 WebSocket 票据，不把长期 JWT 放入连接 URL；页面隐藏时关闭连接，断线时重新领取票据后重连。
- 水位为原始ADC，不是厘米；缺测显示 `--`。历史使用服务端接收时间。
- 人工控制二次确认后操作真实设备。DISPATCHED仅表示已下发，ACKNOWLEDGED才表示设备确认；刷新读取回执，不乐观修改设备运行状态。
- 网络超时可能发生在后端已接收命令之后，先刷新回执再决定是否重试。退出只清除本机令牌，后端目前没有JWT服务端撤销能力。
