# 小程序本地开发说明（miniapp）

## 概述

`miniapp/` 是可通过 HBuilderX 导入的**传统 uni-app Vue3 工程**（非 uni-app x），目前用于本地测试，不上线。默认演示模式；2026-10-14 新增真实后端模式，接入账号登录、概览统计、设备列表/控制回执与历史分页。

## 连接现有后端（MINI-04）

1. 使用项目原有开发配置启动 Java 后端。小程序不会代为启动数据库、Redis 或 MQTT。
2. 在小程序「我的」填写后端根地址，例如 `http://localhost:8080`，点击「连接真实后端」。地址不含 `/api`、账号密码或查询参数。
3. 点击「账号登录」，使用现有系统用户名和密码。当前接入账号密码登录，注册及 OAuth 尚未迁移。令牌仅在内存保存，重启小程序后需要重新登录；本地仅保存模式与后端地址。
4. 概览与设备页进入时刷新，可点击「刷新数据」再次获取。历史页可选设备和时间范围、加载更多；一次查询冻结截止时间，避免翻页时窗口漂移。当前没有 WebSocket 推送。
5. 设备控制需二次确认，会向真实设备下发命令；`DISPATCHED` 仅代表已下发，只有 `ACKNOWLEDGED` 表示设备确认。回执通过刷新获取。离线、禁用、归档、待确认或正在发送时禁止操作。网络失败可能发生在后端接收命令之后，应先刷新回执确认，避免重复操作。
6. 开发者工具使用本机 HTTP 调试时，如遇域名校验拦截，在该项目「详情 → 本地设置」中由开发者手动勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。这仅用于本地测试，仓库未关闭 `manifest.json` 的域名校验。正式发布需另行配置合法 HTTPS 域名。
7. 模拟器访问本机服务可用 `localhost`；真机上的 `localhost` 指手机自身，需要改为电脑同一局域网地址并保证服务可达。浏览器预览还受后端 CORS 限制，应使用项目允许的前端来源。

真实模式不会在错误时回退演示数据。更换地址、切换模式、退出或认证失效时清空真实用户数据；晚到的请求不能恢复旧会话。水位按后端原始 **ADC** 展示，未换算厘米；缺测值显示 `--`。退出清除本机令牌，当前后端没有 JWT 服务端撤销能力。

## 本地编译步骤

1. 打开 HBuilderX（`/Volumes/out/Applications/HBuilderX.app`）。
2. 选择「文件 → 导入 → 从本地目录导入」，选择本项目 `miniapp/` 目录。
3. 在项目根 `manifest.json` 中确认 `vueVersion` 为 `3`；微信小程序 AppID 已配置为用户提供的测试号 `wx072082beff11b3e7`。根级 DCloud `appid` 与微信 AppID 是不同字段，当前根级字段仍为空。
4. 菜单「运行 → 运行到小程序模拟器 → 微信开发者工具」，选择微信开发者工具路径。
5. 微信开发者工具应导入 `miniapp/unpackage/dist/dev/mp-weixin/` 编译目录，不是 `miniapp/` 源码目录。当前已配置测试号；更换 AppID 时修改 `manifest.json` 的 `mp-weixin.appid` 并在 HBuilderX 重新编译。
6. 也可选择「运行 → 运行到浏览器」检查页面。本工程已提供 Vue 3 所需的 `index.html`；浏览器通过不等同于微信模拟器或真机通过。
7. 若首次编译提示缺少 Sass 编译器，按 HBuilderX 官方插件提示安装 `compile-dart-sass` 后重新运行。本机此次已完成安装。

## 无 AppID 时的测试模式限制

- 初次搭建时微信 AppID 留空，现已配置用户提供的测试 AppID。测试号不代表已注册可正式发布的小程序。
- 测试号可用能力以当前工具和账号为准；初期网络受阻现已恢复，见文末 TUN 修复记录。
- 本工程未使用微信登录、云开发等平台能力；可用 HBuilderX 的 Web 预览或微信模拟器检查页面。

## 演示边界（重要）

- `demo` 模式不请求真实 API；登录页也提供独立的「进入演示」，切换后清除真实登录态。
- 演示设备控制及报警、自动化、仿真、研究等未迁移页面**只修改本地演示状态**（见 `miniapp/utils/demo-store.js`）。真实模式的设备控制具有真实下发能力。
- 支付演示为**模拟结果，无真实扣款**。
- AI 助手为**本地固定回复**，不调用任何 LLM。
- 研究示例运行指标为**演示占位值**，不复制冻结论文结论，不声称田间实测或生产验证。
- 数据导出明确标注为**未接入**。
