# Codex 独立审计记录

## 审计范围

- 冻结结果目录：`rag_experiment_20260812_101005`
- 语料：12 个来源、20 个知识块
- 评测：validation 16 题、test 16 题；BM25 与 hybrid 分别评估
- 完整 confirmatory 的 16 题 test 每个检索器执行一次；阈值仅由 validation 选择
- 开发期 smoke 曾使用固定 4 题 test 子集，因此本结果不是严格盲测，只能作为项目内部冻结小样本评估

## 独立复核结果

1. `question_results.csv` 共 64 行：2 个检索器 ×（16 validation + 16 test），题数与 manifest 一致。
2. 122 项 Python 单元/集成测试全部通过；`git diff --check`通过。
3. BM25 test：6/6 个 OOD 正确拒答，10/10 个域内问题均回答；引用 ID 有效性 1.000，引用覆盖率 0.769，引用精确率 0.833。
4. hybrid test：4/6 个 OOD 正确拒答，10/10 个域内问题均回答；引用 ID 有效性 1.000，引用覆盖率 1.000，引用精确率 0.520。
5. hybrid 的两项误答为：
   - `q_test_011`：湖南洞庭湖区水稻 AWD 最佳干燥天数；
   - `q_test_013`：分蘖期具体 AWD 水位阈值。
6. 这些失败结果已保留，未据此修改阈值、规则、gold 标注或测试问题。

## 结论边界

当前内部基准支持在后续 Java 集成中优先采用 BM25 作为保守默认检索器；hybrid 保留为失败/对照方案，不应因 Recall@3 较高而上线为默认安全问答链路。该结论不代表 BM25 在更大语料、真实用户问题或田间条件下必然更优，也不是 LLM 答案事实正确率或农业处方有效性证明。
